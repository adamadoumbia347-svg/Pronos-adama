Perguntas frequentes

De que cidades partem voos para Dubai?

A Escale compara os voos para Dubai a partir de Genebra, Lyon, Paris, Bruxelas, Londres.

Qual é o voo mais curto para Dubai?

A partir de Paris, conte cerca de 6 h 45 de voo (voo direto).

Quando reservar um voo barato para Dubai?

Em geral dois a três meses antes da partida. Reserve mais cedo para de novembro a março, quando faz menos calor: os preços sobem muito.

Que aeroporto em Dubai?

Os voos chegam a Dubai International Airport (código DXB).
