Widget gratuit « Prix des vols »

Affichez sur votre site le prix du moment d'un trajet, par exemple Paris → Dakar. Il se met à jour tout seul. Gratuit, sans inscription, sans cookie.

1. Choisissez le trajet

2. Aperçu

3. Copiez ce code sur votre site

Collez-le dans une page ou un article (bloc « HTML personnalisé » sur WordPress, Wix, Blogger…).

Questions fréquentes

Est-ce vraiment gratuit ? Oui. Le widget n'affiche aucune publicité et ne dépose aucun cookie chez vos visiteurs.

D'où viennent les prix ? Ce sont les prix aller-retour les plus bas repérés récemment pour le mois prochain. Le tarif exact se confirme sur le site de réservation.
