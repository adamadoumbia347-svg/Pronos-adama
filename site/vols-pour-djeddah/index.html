À savoir avant de réserver un vol pour Djeddah

Les vols pour Djeddah partent de 12 villes : Tunis, Kano, Alger, Douala, Niamey, Lagos, Paris, Casablanca, Abidjan, Bamako, Conakry, Dakar.

Le vol le plus court part de Tunis (environ 4 h 30) ; le plus long de Dakar (environ 8 h).

Les prix sont les plus hauts pendant le Ramadan, le Hajj et les vacances scolaires : pour payer moins cher, évitez ces dates ou réservez deux à trois mois à l'avance.

Comparez aussi les vols avec escale : sur les longues distances, une escale bien placée fait souvent baisser le prix.

Conseils pour ces trajets

  • Comparez les compagnies du Golfe et les vols avec escale : les écarts de prix selon le jour de départ sont fréquents.
  • Pour la Omra, réservez le plus tôt possible avant le Ramadan : les prix montent fortement. Médine (MED) est une alternative d'arrivée.
